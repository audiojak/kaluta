# Keyboard shortcuts

Every action in Kaluta can be reached from the keyboard (spec §14.3). The app shows
this list under **Help › Keyboard Shortcuts** (⇧⌘/). It is generated from
`macos/Kaluta/App/KeyboardShortcuts.swift`.

## Mail

| Keys | Action |
|---|---|
| `⌘N` | New message |
| `⌘R` | Reply |
| `⇧⌘R` | Reply all |
| `⇧⌘F` | Forward |
| `⌃⌘A` | Archive |
| `⌃⌘I` | Move to Inbox |
| `⌘⌫` | Move to Trash |
| `⇧⌘U` | Mark as read or unread |
| `⇧⌘L` | Star or unstar |
| `⇧⌘I` | Load remote images |
| `⇧⌘N` | Check for new mail |

## Finding mail

| Keys | Action |
|---|---|
| `⌘F` | Search mail |
| `⌘1 – ⌘6` | Inbox, Starred, Sent, Drafts, Archive, Trash |
| `⌃1 – ⌃9` | Switch to account 1–9 (Kaluta › Accounts) |

## In the thread list

| Keys | Action |
|---|---|
| `↑ ↓  or  j k` | Previous or next thread |
| `e` | Archive |
| `#  or  ⌫` | Move to Trash |
| `u` | Mark as read or unread |
| `s` | Star or unstar |
| `l` | Label… (filter, or type a new `a/b` path to create it) |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `c` | New message |
| `/` | Search mail |

## In Clean Up's groups

*Mailbox › Clean Up Mailbox…* opens Clean Up (no shortcut: it is used a few
times a year). Ticks, not the highlight, are what these act on.

| Keys | Action |
|---|---|
| `↑ ↓  or  j k` | Previous or next group (`⇧` and `⌘` highlight several) |
| `Space` | Tick or untick the highlighted groups |
| `e` | Archive every message in the ticked groups |
| `#  or  ⌫` | Move them to the Trash |
| `!` | Mark them as spam |
| `⌘Z  ⇧⌘Z` | Undo or redo, as in the mail window |

## Writing

| Keys | Action |
|---|---|
| `⇧⌘D` | Send |
| `⇧⌘A` | Attach files |
| `⌘B  ⌘I  ⌘U` | Bold, italic, underline |

## Agents and routines

| Keys | Action |
|---|---|
| `⌘K` | Ask the agent |
| `⌥⌘I` | Show or hide the agent panel |
| `⌥⌘R` | Routines |

With Full Keyboard Access on (System Settings › Keyboard), Tab reaches every button,
including approvals in the agent panel.
